# VAULT · UI

Static front-end of a personal encrypted vault. It runs entirely in the browser:
no backend, no accounts, no telemetry. Vault data stays in the browser's local
storage and is encrypted locally with the master password plus a 26-character
recovery code.

This repository contains UI assets only and is published via GitHub Pages to get
HTTPS (required for Service Worker and PWA installation). Vault data is never
uploaded here.

Test stage: do not store real credentials yet.
